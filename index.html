Asistente que sugiere acciones de mejora ante un incidenteAssistant that suggests improvement actions for an incident

Cuando se notifica un incidente de seguridad del paciente, busca los casos más parecidos entre 1000 descripciones históricas y propone acciones de mejora basadas en ellos.

La búsqueda es semántica, por similitud de vectores: cada descripción se convierte en un embedding y se recuperan las más cercanas en significado al incidente nuevo. Esos casos se pasan al LLM como contexto. Los embeddings y la búsqueda corren en local.

When a patient-safety incident is reported, it finds the most similar cases among 1000 historical descriptions and suggests improvement actions grounded in them.

Retrieval is semantic, by vector similarity: each description is turned into an embedding and the ones closest in meaning to the new incident are retrieved. Those cases are passed to the LLM as context. Embeddings and retrieval run locally.

RAG, ChromaDB, Ollama (nomic-embed-text), Dash, Python
